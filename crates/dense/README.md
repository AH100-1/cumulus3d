# skyrecon-dense

왜곡 보정과 다시점 조밀화(깊이맵 추정 → 필터 → 후처리 → 융합 → PLY).

PatchMatch 실행 자체(한 스케일의 적·흑 전파, 뷰 선택, 정제, 판독)는 [`PatchMatchBackend`](src/kernel.rs) 를 구현한
백엔드가 맡는다. 현재 백엔드는 `skyrecon-cuda` 의 `CudaPatchMatch` 하나이고, 백엔드가 없으면 조밀화는 오류를 돌려준다.
이 크레이트는 그 바깥(장면, 이웃 선택, 깊이 범위, 다중 스케일 진행, 상향 표본, 세부 복원 판정, 필터 문턱, 후처리,
융합, 통계)을 맡는다.

## 처리 흐름

1. **장면**: 왜곡 보정된 모델(핀홀) + 영상 → 뷰(K·자세·회색/컬러). 장면 안 픽셀 좌표는 정수 = 픽셀 중심(주점 −0.5).
2. **이웃 뷰**: 희소점 트랙으로 뷰 쌍의 공유 점 수와 삼각측량각 75 분위를 구해, 각이 1° 이상인 뷰를 공유 수 순으로 최대 10개.
   선택적으로 기준선 방위각 구간별 감쇠로 방향이 고르게 퍼지게 고른다(같은 위치의 다른 카메라는 광축 방향 구간).
3. **깊이 범위**: 관측 희소점 깊이의 1%/99% 값에 0.75/1.25 배. 무작위 초기화에만 쓴다.
4. **다중 스케일**(축소율 0.5, 최대 3단): 최저 스케일은 무작위 초기화 광도 실행, 위 스케일은 결합 양방향 상향 표본 →
   세부 복원(상향 가설 비용 − 광도 실행 비용 > 0.1 인 픽셀은 광도 실행 결과로 교체) → 기하 일관성 실행 2회
   (모든 기준 뷰가 직전 회차 깊이 스냅숏을 읽는 이중 버퍼라 실행 순서와 무관). 선택적으로 무늬 약한 픽셀(기준 패치 분산 < 문턱)은
   거친 스케일 평면을 추가 후보로만 평가한다(비용에는 섞지 않음, 실측에서 이득이 없어 기본 끔).
5. **판독·필터**: 5×5 중앙값 평면 필터 뒤, 원천 뷰마다 삼각측량각 ≥ 3°, 입사 cos > 0, 방출 가시 확률 ≥ E(0.9),
   순·역 재투영 ≤ 1 px 를 모두 만족한 뷰가 2개(원천 수가 적으면 그 수) 이상인 픽셀만 남긴다.
6. **후처리**: 상대 깊이 연속 성분 중 작고(영상 넓이 비율) 비용이 큰 조각 제거, 선택적으로 밝기 경계에서 멈추는 틈 메우기.
7. **융합**: 기본은 일치 융합 — 기준 픽셀의 점을 겹침 뷰에 투영해 깊이(상대 1%)·재투영(2 px)·법선(10°)이 맞는 뷰가
   5개(기본) 이상이면 기준과 일치 점들의 평균. 평균 가중치는 스테레오 오차 전파에서 나온 깊이 분산의 역수
   `σ_d = d²·σ_px/(f·b)`, `σ_px = 0.25 + 비용`(픽셀), `b` 는 뷰와 원천 뷰들의 중심 거리 중앙값. 일치에 쓰인 다른 뷰 픽셀은
   표시해 다시 기준으로 쓰지 않는다(뷰 순서로 정해져 결정적). 다른 방식으로 이웃의 이웃 깊이 우선 확장 + 성분별 중앙값
   융합도 있다(행 띠 병렬, 원자적 점유 표시).
8. **출력**: PLY(x y z nx ny nz red green blue, 27 바이트/점).

## 프로파일

| | fast(기본) | quality |
|---|---|---|
| 창 | 반경 5, 간격 2 (36 표본) | 반경 5, 간격 1 (121 표본) |
| 최저 스케일 | 광도 6 + 기하 2×2 | 광도 7 + 기하 2×6 |
| 중간 스케일 | 세부 복원 3(상향 가설에서 시작) + 기하 2×2 | 세부 복원 6(무작위 시작) + 기하 2×6 |
| 최고 스케일 | 세부 복원 3 + 기하 2×2 | 세부 복원 6 + 기하 2×6 |

일치 융합 최소 일치 뷰 5 는 실영상 240장(960×539)에서 점 수가 기존 비교 기준(약 1,400만)의 ±10% 에 들도록 고른 값이다
(2 → 2,410만, 4 → 1,620만, 5 → 1,350만, 6 → 1,120만).

## 결정성

픽셀 난수는 (시드, 영상 이름 해시, 스케일, 실행, 반복, 반쪽 단계, 픽셀) 로 정해지는 카운터 기반 수열이라 스레드 배치와
무관하다. 기하 실행은 스냅숏 이중 버퍼라 뷰 처리 순서와 무관하다. 일치 융합도 결정적이다(확장 융합은 병렬일 때 아님).

## 깊이맵 캐시

`DepthMapCache`: (영상 이름 + K·자세·크기 해시, 설정 해시) → 필터 전·후 깊이, 법선, 비용. 적중한 뷰는 다시 계산하지 않고
다른 뷰의 기하 실행에는 필터 전 깊이를 축소해 원천 깊이로 준다. 겹치는 구역 재사용용이며 기본은 끔.

## 시험

- `cargo test -p skyrecon-dense`: 손계산 기준값(방출 정규화 A = 1.330950, E(0.9) = 0.432096 등, 사전확률, 분위수, 깊이 범위),
  이웃 선택, 상대 기하, 상향 표본·중앙값 필터, 합성 장면 참 깊이맵 융합(표면 거리, 허용치, 결정성), 후처리, PLY 배치.
- GPU 정확도는 `skyrecon-cuda` 의 `tests/patchmatch_gpu.rs`(합성 장면 참값과 비교).
